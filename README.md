My work asks how AI can move from strong benchmark results to systems people can actually use. I work on model efficiency, visual perception, medical imaging, multimodal reasoning, and agentic systems, with an emphasis on methods that stay useful beyond curated datasets.

I am currently especially interested in workflow-facing AI: clinical agents, deployable medical AI, trustworthy evaluation, and efficient models that can run under real resource constraints.
